## Project Description

This project is a personal portfolio website created using HTML, CSS, JavaScript and jQuery.

The main purpose of this assignment is to practice jQuery selectors, CSS manipulation, effects, DOM manipulation, form handling and animations.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- jQuery 3.7.1
